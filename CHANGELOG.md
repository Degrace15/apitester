Changelog

All notable changes to Api Tester are documented here.

[1.1.0] - 2026-08-09

Added

- New tab-based user interface.
- Request tab for API URL and HTTP method.
- Headers tab for HTTP headers.
- Body tab for JSON request bodies.
- Response tab for server responses.
- Support for GET, POST, PUT, PATCH and DELETE requests.
- HTTP status display.
- Request response time measurement.
- JSON response formatting.
- Text response support.
- Improved mobile interface for Acode.



Fixed

- Improved validation of HTTP methods.
- Improved validation of JSON headers.
- Improved validation of JSON request bodies.
